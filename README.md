# 작은 동네 서점 — 30초 홍보영상 스토리보드

손님이 줄어 고민하던 서점 주인이 가게 문을 닫은 뒤, 책 속 캐릭터들이 깨어나 직접 홍보영상을 만들고 사람들을 다시 서점으로 불러오는 6장면 이야기입니다.

엑셀 파일은 두 시트로 구성되어 있습니다.

1. `6장면 한눈에`: 6개 시작 화면 썸네일과 핵심 내용
2. `장면별 상세`: 캐릭터·공간 일관성 기준, 행동, 대사, 카메라, 분위기, 최종 프롬프트

## 6개 장면

| 장면 | 시작 화면 | 구간 및 내용 |

| 2. 책장이 숨 쉬는 밤 | ![장면 2](storyboard/images/scene_02.png) | `00:05–00:09` 문이 닫히자 세 권의 책이 빛나고 책 속 친구들이 깨어난다. |
| 3. 우리가 알리자! | ![장면 3](storyboard/images/scene_03.png) | `00:09–00:14` 세 친구는 스마트폰을 발견하고 직접 홍보영상을 만들기로 한다. |
| 4. 책 속 친구들의 촬영 | ![장면 4](storyboard/images/scene_04.png) | `00:14–00:19` 도도는 진행, 잉크 경은 연출, 루미는 조명을 맡아 촬영한다. |
| 5. 마법 같은 업로드 | ![장면 5](storyboard/images/scene_05.png) | `00:19–00:24` 영상이 금빛 책갈피가 되어 밤의 동네로 퍼진다. |
| 6. 다시 열린 이야기 | ![장면 6](storyboard/images/scene_06.png) | `00:24–00:30` 영상이 알려지며 사람들이 다시 서점을 찾고 미라는 웃음으로 맞는다. |

## 일관성 기준

- **한미라 — AI 제안:** 은빛이 섞인 짧은 단발, 둥근 짙은 초록 안경, 겨자색 카디건, 남색 앞치마, 황동 열쇠
- **도도 — AI 제안:** 주황 여우, 청록 스카프, 작은 황갈색 가방, 황동 돋보기
- **잉크 경 — AI 제안:** 남색 종이 갑옷, 금빛 별 문양, 자주색 깃털, 연필 모양 검
- **루미 — AI 제안:** 짙은 곱슬 단발, 라벤더 망토, 은청색 날개, 은빛 별 지팡이
- **서점 공간 — AI 제안:** 짙은 청록 벽, 호두나무 서가, 중앙 원형 테이블, 황동 사다리, 왼쪽 계산대와 초록 스탠드, 오른쪽 아치형 창문

사용자가 제공하지 않은 세부 설정과 사건은 엑셀 및 상세 문서에서 `AI 제안`으로 표시했습니다.
